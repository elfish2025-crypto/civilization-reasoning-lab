# Theories

Theory Node 是对 Question Node 的阶段性解释，必须挂靠到问题 ID，不是一级独立资产。

Theory Node 是理论生命树的主要分叉单位。CRL 的主干关系是：

```text
Question Node -> Theory Node -> Report Node
```

报告通常用于展开、支持、比较、修正或反驳理论，而不是替代理论层。
