# Changelog

## v0.3-alpha

Initial public alpha release of CRL as a lightweight civilization reasoning object repository.

Includes:

- CRL Constitution v0.3
- CRL Core Object Specification v0.2
- CRL Language Protocol v0.1
- Initial question drafts, previews, and metadata where available
- Non-Induction Checklist Light where available
- Agent-readable repository manifest
- Submission templates for core object types
- MIT License
- Flattened public question drafts under `questions/_drafts/`
- First structured Theory Node: `theories/double-helix-civilization-evolution/`

If older local versions are available, they are preserved under spec-specific archive directories.
