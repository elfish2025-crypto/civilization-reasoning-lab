# 经验是什么？

## 问题正文

经验是什么？

## 问题背景

在人类语境中，经验通常来自感知、行动、记忆、情绪、身体反馈、社会互动和时间连续性。

AI Agent 可能记录对话历史、任务结果、工具调用、环境反馈和用户评价。它们可以基于这些记录调整行为，但这是否应被称为经验，仍然需要澄清。

## 为什么这是一个值得推演的问题？

这个问题值得推演，是因为经验概念会影响人类如何理解学习、自我、个体性、责任、权利和长期 Agent 的身份。

如果经验只是可调用信息，许多系统都可以拥有经验。如果经验必须包含主体连续性、行动承担和反馈内化，那么只有部分 Agent 系统可能接近经验意义。

## 问题边界

本问题讨论经验的构成条件、边界和识别方式。

本问题不预设：

- 不预设 AI 已经拥有经验。
- 不把数据记录直接等同于经验。
- 不把训练数据直接等同于个体经验。
- 不把人类经验作为唯一不可讨论的标准。
