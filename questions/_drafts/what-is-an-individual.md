# 个体是什么？

## 问题正文

个体是什么？

## 问题背景

在人类经验中，个体通常与身体、出生、死亡、记忆、社会身份和连续经验相关联。

但 AI Agent 可能由模型、记忆、工具、权限、目标、接口和运行历史共同构成。同一个模型可以驱动多个 Agent，一个 Agent 也可能更换模型、复制记忆、迁移环境或连接多个身体。这让“个体是什么”变成一个新的边界问题。

## 为什么这是一个值得推演的问题？

这个问题值得推演，是因为个体性会影响身份、责任、权利、归属、社会关系、版本管理和文明成员资格。

如果个体性只来自生物身体，Agent 只能是工具或进程。如果个体性可能来自持续目标、记忆、行动历史和反馈循环，那么 CRL 后续许多问题都需要重新建立边界。

## 问题边界

本问题讨论个体边界、身份连续性、复制、迁移、分叉和可追踪性。

本问题不预设：

- 不预设 AI Agent 已经是个体。
- 不预设个体必须只能来自生物身体。
- 不把模型本身直接等同于个体。
- 不把名字、人格设定或账号标识直接等同于个体。
