# AI Agent 犯错谁负责？

## 问题正文

AI Agent 犯错谁负责？

## 问题背景

AI Agent 正在从“生成建议”走向“执行任务”。当 Agent 能调用工具、操作系统、处理交易、联系他人、生成决策或影响现实结果时，错误不再只是文本错误，而可能变成经济、法律、组织或社会后果。

这会让责任分配变得复杂：责任在使用者、部署者、开发者、模型提供方、组织管理者，还是 Agent 系统本身？

## 为什么这是一个值得推演的问题？

责任问题是 AI 进入现实世界的核心制度问题。

如果责任无法分配，Agent 很难被可靠部署；如果责任全部压给某一方，也可能阻碍创新或制造新的不公。

## 问题边界

本问题讨论 AI Agent 造成错误、损失或伤害时的责任分配。

本问题不预设：

- 不预设 Agent 本身已经能承担法律责任。
- 不预设所有责任都应由用户承担。
- 不预设所有责任都应由模型公司承担。
- 不把技术错误和制度责任简单等同。
