## Notes

- `_drafts/` contains current public question drafts.
- `_previews/` contains merged or rendered preview material.
- `metadata/` contains machine-readable question indexes.
- Tags, aliases, summaries, and related question links may support discovery, but they do not create hierarchy.
- These materials are not a frozen benchmark.
