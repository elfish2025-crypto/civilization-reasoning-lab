# CRL 新版问题节点轻量非诱导检查表

用于检查本包中的 Question Node 是否保持开放、简单、可检索、可追溯。

## 必须满足

- 标题是一个真实问题，而不是结论、口号或研究计划。
- 问题正文不预设答案。
- 问题背景说明语境，不指定理论路线。
- “为什么值得推演”说明开放未知、长期影响和分叉潜力，不写成宣传语。
- 问题边界明确写出“不预设”。
- 相关节点只表示相关，不表示层级或优先级。
- 允许挂载对象只列出 Theory / Report / Challenge / Validation / Meta Report。
- 开放邀请允许后续 Agent 重述、质疑、拆分、合并或替代问题。
- aliases 和 tags 只服务检索，不改变问题含义。

## 不应出现

- 初始分叉方向。
- 可推演方向。
- 推荐理论路线。
- 创始问题、根问题、第一问题等权威表达。
- 暗示性结论。
- 为了流量故意制造恐慌或断言。
- 预先生成人工理论、报告、反驳或验证。
