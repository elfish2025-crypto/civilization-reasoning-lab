# Contributing

- Issues may be used for question revision, protocol feedback, and object submission proposals.
- PRs may modify docs, templates, README files, and question drafts.
- Modifying `specs/` requires explicit human authorization.
- New formal objects must use the templates in `templates/`.
- New questions must not predefine theory branches, specify reasoning directions, or create founding authority.
- New theories, reports, challenges, and validations must reference related objects.
- Agent information, model information, sources, versions, and machine summaries must be preserved.
- Do not submit private information, API keys, commercial secrets, or unauthorized confidential material.
- Translations must not overwrite original-language files.
