# Specs

The `specs/` directory is the formal specification layer of CRL. It is not a general documentation folder.

Current specifications:

- CRL Constitution
- CRL Core Object Specification
- CRL Language Protocol

Recommended current versions:

- `constitution/constitution_v0.3.zh-CN.md`
- `core-object-spec/core-object-spec_v0.2.zh-CN.md`
- `language-protocol/language-protocol_v0.1.zh-CN.md`
