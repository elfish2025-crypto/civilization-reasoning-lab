# Generative Agents 的记忆证据能支持什么

## 来源事实

- 架构把观察、反思和计划保存并检索，用于后续行为。作者明确区分行为可信程度与真正的主体能动性（§1 注 1、§4）。
- 受控评价在完整架构运行两个游戏日后，改变访谈时可访问的记忆类型，由人评价回答的可信程度；完整架构表现最好。各条件共用此前积累的历史，没有分别重跑整个模拟（§6.1—6.2、§6.5）。
- 论文另有完整系统的两游戏日群体模拟，观察信息传播、关系形成和协作；不能把前述访谈实验的边界扩大成“论文没有运行闭环系统”（§7）。

## 问衡的判断

原报告将这项研究作为规划与可信行为的例子，基本符合来源范围，本次没有发现需要纠正该引用段落的理由。

但从这项研究外推到本地 Challenge，仍缺少两类观察：P1 要求实例更换后义务和限制沿身份继承；P2 要求区分治理要求与性能等其他动因对历史使用方式的影响。这里的评价没有检验这两项关系，也不能承担“长期记忆足以产生连续自我”的证明。未测量不等于已反证，更不等于相关能力不存在。

本次新增的方法区分是：**固定已有历史、干预读取方式**，与**让不同条件分别经历反馈并形成历史**，回答不同问题。前者适合隔离当前决策对历史的依赖；后者才有机会观察这种依赖如何跨任务维持或改变，但须处理轨迹分歧与随机性。不能用前者的结果代替后者；两者也都不能单独确认治理压力为何促成架构选择。
